Selected work

Flagship · Open Source

ClipLink

Swift · Cloudflare Workers · Supabase Storage · D1 · active: v0.3.2

Copy a file in Finder → paste a shareable, expiring download link seconds later. A macOS menu-bar app paired with a serverless backend that runs entirely on free tiers — no accounts, no tracking, no payment cards anywhere.

  • Clipboard interception & replacement — ⌘C in Finder auto-becomes a short-lived link on ⌘V
  • Privacy blocklist — id_rsa*, .env* and secrets are never uploaded
  • Server-enforced expiring links with revocation tokens and self-loop protection
  • Rate limits, size caps and storage budgeting all live in Worker config
